# Complaint Management System

## 📌 Project Description

This project is a multi-role Complaint and Feedback Management System designed to allow users to report issues related to specific organizations.

Users can register, log in securely, and submit complaints with optional file attachments. Each complaint is assigned to a specific organization.

Organization representatives can access and manage complaints related to their organization, update their status, and respond to users.

Administrators have full control over the system, including managing users, organizations, and all complaints.

The system demonstrates role-based access control, file handling, session management, and full-stack web development using Spring Boot.

---

## 👥 User Roles

- **User**: Submit and track complaints
- **Representative**: Manage complaints for their organization
- **Admin**: Manage users, organizations, and the entire system

---

## 🧾 User Stories

### 🟢 User
As a user  
I want to submit a complaint to a specific organization  
So that the responsible authority can handle my issue  

### 🔵 Representative
As a representative  
I want to view complaints related to my organization  
So that I can respond and resolve them efficiently  

### 🔴 Admin
As an admin  
I want to manage users and organizations  
So that the system operates correctly
